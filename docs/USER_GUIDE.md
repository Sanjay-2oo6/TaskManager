## Getting Started

### First Time Login

1. **Open the Application**
   - Mobile: Launch the Task Manager app
   - Web: Navigate to https://taskmanager.com

2. **Enter Your Credentials**
   - Email: Provided by your administrator
   - Password: Set by your administrator (change on first login)

3. **Set Up Notifications** (Mobile only)
   - Grant notification permissions when prompted
   - Enable location access if required for your role

4. **Explore the Dashboard**
   - Familiarize yourself with the navigation menu
   - Review any pending tasks assigned to you

### Changing Your Password

1. Navigate to **Profile → Settings**
2. Click **Change Password**
3. Enter your current password
4. Enter new password (must include uppercase, lowercase, number, and special character)
5. Confirm new password
6. Click **Save Changes**

## Managing Tasks

### Viewing Task Details

1. **Open Tasks Tab**
2. **Tap/Click on a Task**
3. **Review Information:**
   - Task title and description
   - Due date and priority
   - Assigned team members
   - Admin notes and instructions
   - Reference files (if provided)
   - Task history

### Updating Task Status (Employees)

1. Open the task
2. Click **Update Status**
3. Select new status:
   - Mark as **In Progress** when you start
   - Mark as **Submitted** after uploading proof
4. Add optional notes
5. Click **Confirm**

### Creating Tasks (Admin/Assigner Only)

1. **Navigate to Tasks → New Task**
2. **Fill in Required Information:**
   - **Title**: Clear, descriptive name
   - **Description**: Detailed instructions
   - **Assign To**: Select team member(s)
   - **Due Date**: Set realistic deadline
   - **Priority**: Choose appropriate level
3. **Add Optional Elements:**
   - Admin notes (private instructions)
   - Reference files (specs, images, documents)
   - Dependencies (tasks that must complete first)
4. **Click Create Task**
5. **Notification** is sent automatically to assignees

### Editing Tasks (Admin/Assigner Only)

1. Open the task
2. Click **Edit** button (pencil icon)
3. Modify any fields
4. Click **Save Changes**
5. Team members receive notification of updates

### Deleting Tasks (Admin Only)

1. Open the task
2. Click **More Options** (⋮)
3. Select **Delete Task**
4. **Confirm deletion** (cannot be undone)
5. All related messages and submissions are also removed

## Submitting Work

### Taking Before/After Photos

#### Best Practices for Quality Submissions

**Before Photos:**
- Show the initial state clearly
- Include full context (surrounding area)
- Good lighting (natural light preferred)
- Multiple angles if needed
- Timestamp visible (if required)

**After Photos:**
- Same angle as before photo
- Show completed work clearly
- Include entire work area
- Good lighting matching before photos
- Clean and organized presentation

### Submission Process

1. **Open the Task**
2. **Click "Submit Proof" Button**
3. **Add Before Photos**
   - Click **Camera** to take new photo
   - Click **Gallery** to select existing photos
   - Can add multiple photos (up to 10)
4. **Add After Photos**
   - Same process as before photos
5. **Write Description**
   - Explain what was done
   - Note any issues encountered
   - Mention materials/tools used
6. **Review Submission**
   - Check all photos are clear
   - Verify description is complete
7. **Click Submit**
8. **Confirmation** appears when successful

### What Happens After Submission

1. **Task status** changes to "Submitted"
2. **Admin/Manager** receives notification
3. **Review process** begins (usually within 24 hours)
4. **You receive notification** when reviewed with feedback

### Handling Rejections

If your submission is rejected:

1. **Read Admin Feedback** carefully
2. **Review Reference Files** if provided
3. **Ask Questions** in task chat if unclear
4. **Redo the Work** addressing issues
5. **Resubmit** with corrections
6. **Note**: Multiple rejections may require manager discussion

## Communication

### Task Chat

Real-time messaging for each task allows quick clarification and updates.

#### Sending Messages

1. Open the task
2. Navigate to **Chat** tab
3. Type your message
4. Optionally attach files
5. Press **Send**
6. Message delivered instantly to all task members

#### Message Features

- **Read Receipts**: See who has read your messages
- **Typing Indicators**: Know when someone is responding
- **File Attachments**: Share documents, images
- **System Messages**: Automatic updates (status changes, etc.)
- **Search**: Find previous messages
- **Notifications**: Get alerted to new messages

#### Chat Etiquette

✅ **Do:**
- Be clear and concise
- Ask questions early
- Report issues promptly
- Use professional language
- Respond in a timely manner

❌ **Don't:**
- Use all caps (seems like shouting)
- Send spam or off-topic messages
- Share confidential information
- Use inappropriate language
- Send excessive messages

### Submission Comments

Private conversation between employee and reviewer on specific submissions.

**Use Cases:**
- Request specific changes
- Clarify requirements
- Explain unusual circumstances
- Provide additional context

**How to Use:**
1. Open submission
2. Click **Add Comment**
3. Type your message
4. Click **Post**
5. Relevant parties receive notifications

## Mobile App

**iOS:**
1. Download from TestFlight or App Store

### Offline Mode

The app works offline with automatic synchronization when connected.

**What Works Offline:**
- ✅ View previously loaded tasks
- ✅ Write messages (sent when online)
- ✅ Take photos for submissions
- ✅ Draft submissions
- ❌ Login (requires internet first time)
- ❌ Load new tasks
- ❌ Receive real-time updates

**Sync Indicator:**
- 🟢 **Online**: All features available
- 🟡 **Syncing**: Uploading offline changes
- 🔴 **Offline**: Limited features, data queued

### Push Notifications

Stay updated with instant alerts:

**Notification Types:**
- 🚀 **New Task Assigned**: When you get new work
- 📝 **Status Update**: When task status changes
- ✅ **Submission Reviewed**: When admin reviews your work
- 💬 **New Message**: When someone chats on your task
- ⏰ **Deadline Reminder**: 24 hours before due date
- 🔔 **Mention**: When someone tags you

**Managing Notifications:**
1. Go to **Profile → Notification Settings**
2. Toggle specific notification types
3. Set quiet hours (optional)
4. Choose notification sound

- Avoid zooming (move closer instead)

- Check available storage: **Profile → Storage**
- Clear cache if storage low

**Automatic Updates (OTA):**
- App checks for updates on startup

## FAQ

### General Questions

**Q: How do I reset my password if I forgot it?**  
A: Contact your system administrator. For security, passwords cannot be reset within the app and must be changed by an admin via email verification.

**Q: Can I use the app on multiple devices?**  
A: Yes! Your account can be logged in on phone, tablet, and computer simultaneously. Data syncs across all devices.

**Q: How long does my session last?**  
A: You stay logged in for 7 days of inactivity. After 7 days without opening the app, you'll need to login again.

**Q: Is my data secure?**  
A: Yes! All data is encrypted in transit (HTTPS) and at rest. We follow industry-standard security practices.

---

### Tasks & Submissions

**Q: Can I edit a task after it's submitted?**  
A: No, once submitted you cannot edit. If corrections are needed, the admin will reject it with feedback, allowing you to resubmit.

**Q: What if I can't complete a task by the deadline?**  
A: Communicate early! Message the task chat or contact your manager ASAP to discuss extension or reassignment.

**Q: Can I see other employees' tasks?**  
A: No, you can only see tasks assigned to you. Admins and managers can see all tasks.

**Q: What's the maximum file size for uploads?**  
A: 20MB per file, up to 10 files per submission.

**Q: What happens if my submission is approved?**  
A: Task status changes to "Completed". It's added to your completion record and may affect your performance metrics.

---

### Communication

**Q: Are messages private?**  
A: Task messages are visible to everyone assigned to that task plus admins/managers. Submission comments are only visible to you and reviewers.

**Q: Can I delete a message I sent?**  
A: No, messages cannot be edited or deleted. Double-check before sending.

**Q: Why didn't I receive a notification?**  
A: Check:
- Notification permissions are enabled
- App has internet connection
- Notification settings in Profile
- Device's Do Not Disturb mode

**Q: How do I turn off notifications at night?**  
A: Go to **Profile → Notification Settings → Quiet Hours** and set your preferred schedule.

---

### Mobile App

**Q: Why is the app using so much storage?**  
A: Photos are cached locally before upload. Go to **Profile → Storage → Clear Cache** to free up space.

**Q: App won't open/crashes on startup**  
A: Try:
1. Force close and reopen
2. Clear app cache
3. Check for updates
4. Reinstall app (data is cloud-backed)

**Q: Photos won't upload**  
A: Check:
- Internet connection is stable
- File size is under 20MB
- File format is supported (JPEG, PNG, PDF)
- Storage space available on device

**Q: Can I use the app without internet?**  
A: Partially. You can view previously loaded tasks and prepare submissions offline. They'll sync when you reconnect.

---

### Performance & Analytics

**Q: How is my performance measured?**  
A: Metrics include:
- Tasks completed on time
- Submission quality (acceptance rate)
- Response time
- Communication effectiveness

**Q: Can I see my performance statistics?**  
A: Yes, basic stats are in **Profile → My Stats**. Detailed analytics are available to your manager.

**Q: Does rejection affect my performance?**  
A: One rejection isn't critical, but repeated rejections may require performance discussion. Focus on reading instructions carefully and asking questions early.

---

### Technical Issues

**Q: "Invalid credentials" error when logging in**  
A: Either email address or password is incorrect. Double-check capitalization and verify you're using your email address. If still having issues, contact your administrator for password reset.

**Q: "No internet connection" but I'm connected**  
A: Try:
- Toggle airplane mode on/off
- Restart the app
- Check if other apps work online
- Contact IT if issue persists

**Q: Tasks not loading/showing**  
A: 
- Pull down to refresh
- Check filter settings (you might have filtered out tasks)
- Log out and back in
- Contact support if issue continues

**Q: Photos appear blurry in submission**  
A: This is compression for faster upload. Admins see full-quality versions.

## Glossary

**Admin**: User with full system access and management capabilities  
**Assigner**: Team lead or manager who creates and assigns tasks  
**Assignee**: Person(s) assigned to complete a task  
**Before/After Photos**: Visual proof of work completion  
**Dependency**: Task that must be completed before another can start  
**FCM Token**: Technical identifier for push notifications  
**OTA Update**: Over-the-air app update (no app store required)  
**Priority**: Urgency level of a task (Low, Medium, High, Extreme)  
**Status**: Current state of a task (Pending, In Progress, etc.)  
**Submission**: Proof of work sent for review  
**Sync**: Uploading local changes to cloud server
